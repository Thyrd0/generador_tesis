# Generador Automático de Proyecto de Tesis

Aplicación web que genera automáticamente proyectos de tesis siguiendo el esquema de la Universidad Nacional de Trujillo, con formato APA V7 y todas las especificaciones requeridas.

## Características

- ✅ Generación automática de contenido inteligente basado en el tema ingresado
- ✅ Cumple estrictamente con el formato del esquema proporcionado
- ✅ Márgenes, interlineado, fuente y alineación según especificaciones
- ✅ Generación de referencias bibliográficas (mínimo 30, formato APA V7)
- ✅ Árbol de problemas y árbol de objetivos
- ✅ Exportación a PDF y Word
- ✅ Interfaz amigable con Streamlit
- ✅ Backend robusto con FastAPI

## Requisitos

- Python 3.8+
- pip
